decompressPlaceable

open override fun decompressPlaceable(src: ByteArray, dst: ByteArray, dstOffset: Int = 0): Int

从 dstOffset 开始写入解压数据，返回实际写入长度，未使用的区域保持不变。 src 与 dst 不能是同一个数组；异常发生时 dst 可能已被部分写入。 解压长度不一定能从压缩数据提前计算，调用方可提供容量上界并处理容量不足异常。

Throws

CompressionInvalidArgumentException

数组相同或目标偏移无效。

CompressionOutputTooSmallException

目标数组的剩余容量不足。

CompressionOutputLimitExceededException

超过算法实例配置的解压长度限制。

CompressionException

压缩数据损坏、截断、校验失败或格式不受支持。
