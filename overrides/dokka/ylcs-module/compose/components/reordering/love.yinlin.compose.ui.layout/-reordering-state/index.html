ReorderingState

@Stable
class ReorderingState

基于稳定 key 的插入式排序，直接用于现有 Lazy 容器，不持有业务列表。

onMove(from, to) 的两个索引均属于本次移动前的整个容器（包含 header）， 调用方必须同步执行 add(to, removeAt(from))，不需要在向后移动时减一。 连续移动时 from 是拖动项的当前索引，不是手势开始时的索引。 onSettle 只在有效移动结束后调用一次，参数为手势开始、结束时的索引。 手势取消与松手相同，保留已经完成的移动。

数据源切换、插入或删除前应调用 cancelDrag；它终止手势且不触发 onSettle， 不回滚已经由 onMove 修改的数据。key 必须唯一且在移动期间保持不变。
