LinuxSkiaLayerComponent

interface LinuxSkiaLayerComponent

Platform host used by the Kotlin/Native Linux SkiaLayer.

Skiko owns the Skia and Ganesh objects while the embedding toolkit owns the native window and its event loop. Implementations must invoke requestRender on the window thread.
