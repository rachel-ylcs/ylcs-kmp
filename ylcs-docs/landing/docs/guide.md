## 开始使用 {: #start }

??? question "什么是银临茶舍 APP？"
    银临茶舍是基于 Rachel 框架开发的跨平台应用，集资讯、听歌、美图、社区与轻量游戏于一体，面向银临及相关作品的爱好者。

??? question "在哪里可以下载最新版？"
    官网 [yinlin.love](https://yinlin.love) 始终提供最新版本的下载入口，也可以在首页的[平台下载区](index.md#download)选择对应平台。交流 QQ 群也会同步版本消息。

??? question "APP 支持哪些平台？"
    - Android：手机与平板，可直接安装
    - iOS：iPhone 与 iPad，需要自签侧载
    - Windows、Linux、macOS：解压后运行
    - Web / PWA：[web.yinlin.love](https://web.yinlin.love)

    鸿蒙、手表、电视和车载平台暂未支持。

??? question "如何更新 APP？"
    手机端直接覆盖安装，但覆盖前请保留本地数据；桌面端下载新版本压缩包后替换原目录；网页端会自动更新，未生效时可以清理浏览器缓存。

??? question "如何注册账号？"
    注册时的 ID 为 2 至 16 字，密码为 8 至 16 位字母或数字。邀请人可以手动填写，也可以从过滤器中选择；提交后需要主动提醒邀请人审核。不注册仍可使用绝大多数应用功能，账号主要用于社区身份。

??? question "忘记密码怎么办？"
    如果记得账号，可以在设置页直接修改密码。如果忘记密码但仍记得 ID，可以在登录页填写 ID 和新密码，并联系邀请人协助审核。如果不记得 ID，可以检查社区或游戏页中留下的发帖、对局记录。

## 资讯与影像 {: #information }

??? question "资讯页提供哪些内容？"
    资讯板块汇集银临的最新演出活动、微博、超话和抖音内容。日历与活动条展示近六个月的演出信息，点击活动项或资讯轮播图可以进入详情。

??? question "演出详情如何前往购票？"
    活动详情页会保留演出时间、城市和购票入口。已经安装相关购票应用时，链接会直接打开对应演出页面。

??? question "美图页的图片规格是什么？"
    美图页收录演出官方摄影、海报和其他活动写真，图集以 4K 超清规格归档。下载高清图可能需要等待一段时间，请保持网络稳定。

??? question "微博与超话需要登录吗？"
    不需要。微博与超话页面以免登录浏览为主，默认收录银临及相关工作室账号，也可以在用户管理页主动关注其他账号。超话页结构与微博一致，内容按最新动态更新。

??? question "抖音内容在哪些平台可用？"
    抖音板块可以浏览银临相关视频并支持下载，目前仅 Android 端支持。

## 音乐与曲库 {: #music }

??? question "曲库与音质如何？"
    曲库包含 200 余首银临歌曲的最高音质曲目，使用 Rachel 的 MOD 格式组织。MOD 资源仅用于银临茶舍，无法在外部音乐平台直接播放。

??? question "如何为曲库添加歌曲？"
    - 工坊：提供官方无损 MOD，是主要来源
    - 导入与分享：导入其他来源的 MOD 文件
    - 创建：自行设置歌曲信息并补充音频、封面与歌词
    - 平台导入：从第三方平台导入公开音乐或歌单，不支持无版权或需要 VIP 付费的内容

??? question "如何创建歌单并播放？"
    先在歌单页右上角创建歌单，回到曲库页长按多选歌曲，再添加到目标歌单。进入歌单页后点击播放即可。正在播放的歌单可以通过底部音频控件条切换。

??? question "歌单可以云备份吗？"
    歌单支持与账号绑定的云备份与恢复。歌曲 MOD 文件体积较大，不参与备份，卸载应用后本地 MOD 会被删除，请在曲库中按需管理。

??? question "歌词与播放模式如何设置？"
    所有歌曲支持逐行歌词；包含音游资源的歌曲在下载资源后解锁逐字歌词。歌词大小、颜色与悬浮歌词可以在歌词设置页调整。播放模式包括顺序播放、单首循环和随机播放。

??? question "睡眠模式与 MOD 资源有什么作用？"
    睡眠模式会在设定时间结束后自动停止播放器，也可以提前终止。部分 MOD 还包含壁纸、动画、PV 视频与伴奏，可在 MOD 详情页单独管理、替换或删除。

## 世界与社区 {: #world }

??? question "世界页包含哪些游戏？"
    世界页收录与银临歌词相关的互动小游戏，对局来自其他小银子提供的出题与解题。部分对局需要消耗银币，参与前请确认规则。小游戏提供排行榜与历史记录，也包含在线歌词默写和测试期音游。

??? question "发现页可以做什么？"
    发现页用于发表与银临有关的主题帖。导航栏可以切换板块，右上角可以发布主题帖，适合交流演出、作品与现场体验。

??? question "银子页与签到有什么作用？"
    登录后可以维护账号资料。每日签到会获得银币与经验，经验用于提升等级，等级表可以点击等级或称号查看。

??? question "名片与邮箱如何使用？"
    名片页展示账号二维码，其他人可以通过扫码查看主页或关注。邮箱页接收茶舍官方的活动提醒、节日祝福等消息。

??? question "徽章功能开放了吗？"
    徽章功能暂未开放。

## 账号与反馈 {: #account }

??? question "设置页可以调整哪些内容？"
    设置页可以修改账号资料、密码，重置信息或退出登录。还可以配置主题风格、动画速度、音频焦点和悬浮提示等应用偏好。

??? question "音频焦点与悬浮提示是什么？"
    开启音频焦点后，茶舍播放音频时会独占焦点，其他应用播放音视频不会打断。开启悬浮提示后，长按大部分图标可以查看其含义。

??? question "发现问题或有新功能建议如何反馈？"
    可以在 APP 设置中的反馈建议里提交，也可以联系群管理。反馈 Bug 时请尽量附上设备平台、APP 版本、问题描述，以及能够稳定复现的录屏或录像。

??? question "卸载 APP 会丢失哪些数据？"
    歌曲 MOD 与本地文件保存在设备上，卸载后会全部丢失。歌单与部分账号数据支持云备份，但 MOD 文件本身不参与备份，请在卸载前自行确认。
