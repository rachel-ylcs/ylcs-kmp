# Rhyme 录谱交接步骤

## 领取曲目

1. 在 [进度表](PROGRESS.md) 选择一首「待录谱」的曲目，打开同 ID 的 `<ID>.rachelres`。英文歌曲目前标为「英文暂缓」。
2. 草稿已填入歌曲时长 `duration` 和副歌段 `chorus`，单位均为毫秒。时长来自分工表。副歌段按 Mod Manager 的导入规则，将歌曲配置中的每个副歌点 `v` 写成 `{"start": v, "end": v}`，没有副歌点时使用 `[]`。
3. 草稿中的 `lyrics` 已带行起点和逐字时间。所有字的 `scale: 1` 都是占位值。进度表标为「已完成」的资源保留了各自原有的时长、词谱和副歌段。

## 对照谱面录入

1. 找与歌曲录音对应的声乐简谱，确认主旋律、八度、反复段和尾段。遇到漏字、错字、断句或异版时，按同 ID 的音频和 LRC 核对，可参考本地 Mod Manager 歌曲库中的 `lyrics.rachelres`。
2. 用草稿的行时间和逐字时间对齐演唱内容，检查共用时间块、零时长及逆序位置。根据录音保留主唱，剔除标题、演职员、念白和伴唱。共用时间块在草稿中已按字符均分，录谱时可按实际演唱调整。
3. 按 `RhymeLyricsConfig` 编辑旋律，保留字符串 `id`、草稿已有的 `duration` 和 `chorus`。逐字操作的 `end` 是相对该行 `start` 的累积毫秒偏移。
4. 单音填 `Note`，连音填 `Slur`。低音 1–7 编码为 15–21，中音为 1–7，高音为 8–14。沿用既有录谱约定，连音最多录三个音，超过时依次取前三个不同音。遇到升降半音，按谱面音级和八度填写，并在进度表记录受影响的位置或数量。

## 验收并登记

1. 核对 ID、时长、副歌点、歌词覆盖及音符数量，确认逐字结束时间在行内递增并落在歌曲时长内。用同版音频试听起段、副歌和尾段，有条件时在 Mod Manager 或游戏里验证。
2. 校验完成后，直接覆盖该 ID 的 `<ID>.rachelres`。立即在 [进度表](PROGRESS.md) 把对应行更新为「已完成」，补上谱源、人工校正点和试听情况，并更新总计。资料不足时记录卡点，保留当前草稿。
3. 从现有草稿或成品继续编辑即可。常规录谱可直接编辑 JSON 或使用 Mod Manager，每首歌交接仍使用原 ID 的文件名。
